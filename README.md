# Máquina de pegatinas

Control de la máquina de pegatinas: Arduino Mega 2560 + Bluetooth + panel en tablet Android
(protocolo **VirtuinoCM**).

> **Estado:** Ver_8 desarrollada y pendiente de probar en la máquina. **No hay versión oficial nueva**: solo el propietario aprueba versiones oficiales. La Ver_7 sigue siendo la que funciona.

| `arduino/Pegatinas_Ver_8/` | Versión pulida de prueba: leer su `LEEME.md` (cambios, botones nuevos y lista de comprobación) |
| `arduino/Pegatinas_Ver_8/pruebas/` | Pruebas en el PC con un simulador de la máquina |
| `docs/AUDITORIA_ARDUINO.md` | Análisis del sketch, fallos encontrados y opciones |
| `docs/PLAN_VER_8.md` | Plan acordado de la Ver_8 |
| `.github/workflows/` | Pruebas y compilación para Arduino Mega en cada subida (pestaña Actions) |
